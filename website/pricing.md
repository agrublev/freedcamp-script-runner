# Pricing — fsr (Freedcamp Script Runner)
Last updated: 2026-06-20


## Free — Forever

- Price: $0/month
- License: MIT (open source)
- Installation: `npm i -g fscr`
- Users: Unlimited
- Projects: Unlimited

### Included features

- Interactive script picker (`fsr` / `fsr start` / `fsr scripts` / `fsr list`)
- fscripts.md Markdown-based script runner
- Auto-generate from package.json (`fsr generate`)
- Full JavaScript code blocks inside Markdown
- Parallel execution (`fsr run-p`)
- Sequential execution (`fsr run-s`)
- Plugin hook system (pre-task, post-task)
- Plugin discovery (`fsr plugins`)
- Built-in AES file encryption/decryption (`fsr encrypt` / `fsr decrypt`)
- Interactive encrypt/decrypt menu (`fsr encryption`)
- System doctor, auto-fix, and verbose diagnostics (`fsr doctor` / `fsr doctor --fix` / `fsr doctor --verbose`)
- AI-powered conventional commit messages (`fsr commit`)
- Auto Table of Contents (`fsr toc`)
- Version bump (`fsr bump`)
- Smart package upgrade detection (`fsr upgrade`)
- Shell tab completions — `fsr completion install` / `fsr completion uninstall` / `fsr completion status` / `fsr completion generate`; `--shell` / `-s` flag to target bash, zsh, fish, or powershell
- Git branch validation (`fsr branch`)
- History clearing (`fsr clear`)
- Environment profiles (`fsr --env <name>` / `-e`)

There are no paid tiers, no enterprise plans, and no usage limits.
fsr is completely free and open source under the MIT license.
